# Native circuit models

- `breadboard.glb` is the detailed board supplied by the native AR teammate. CircuitGlbBuilder uses HP and excludes its coincident LP proxy.
- `components.json` is generated by `unity/Assets/CircuitXR/Editor/NativeModelExport.cs` from the team's preserved Led, Resistor, and Pushbutton prefabs. Source provenance is in `unity/ASSET_PROVENANCE.md`. Geometry is uniformly normalized, Y-up in meters, with baked transforms, reversed Z/winding for glTF, and original submesh colors.
- Run `./scripts/export-native-models.sh` from the repository root after changing those prefabs, then rebuild Android. Do not edit generated vertex data by hand.
- CircuitGlbBuilder resolves every terminal and wire from the versioned board map. It generates a scene for the current placement, not one static model per example. Raised pin guides are schematic; physical mesh pin fit is not certified. No Uno prefab exists in the source; its proxy stays explicitly schematic.

The builder follows the [Khronos glTF 2.0 specification](https://registry.khronos.org/glTF/specs/2.0/glTF-2.0.html). Regression-test scene outputs are under `app/build/circuit-previews/`.
